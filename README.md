# Algo Visualizer 🚀

A web-based tool to visualize sorting algorithms step by step. Built using HTML, CSS, and JavaScript, it allows users to understand how algorithms like Bubble Sort, Selection Sort, and Insertion Sort work through animations.

---
## 🔧 Features

- 📊 **Visual Array Generation**: Randomly generates bar heights to simulate array values.
- 🎨 **Color-Coded Transitions**:
  - 🟡 Yellow: Bars currently being compared.
  - 🔴 Red: Current minimum in selection sort.
  - 🟩 Green: Sorted bars.
- 🌀 **Sorting Algorithms Implemented**:
  - Bubble Sort
  - Selection Sort
  - Insertion Sort *(Coming soon / WIP if not done)*
- 🕓 **Step Delay Control**: Adjust animation speed using a slider.
